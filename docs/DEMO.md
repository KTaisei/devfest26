# デモ手順

> この文書は旧架空グラフの訓練手順です。通常の `/home`・`/support`・`/helper` は実位置版へ移行しました。旧手順は `/simulation`・`/simulation-support`・`/simulation-helper`・`/simulation-matching` で実施します。実位置版の操作は [REAL_DATA.md](REAL_DATA.md) を参照してください。

すべて訓練用です。キー不要の初期設定ではAPIを1プロセスで起動してください。

ルートURL（`/`）を初めて開くと案内画面（`/welcome`）が表示され、プロフィール登録へ進めます。案内を終えた後はマップへ進みます。直接 `/home` などを開いた場合はその画面を表示します。上部の「使い方」やサイドバーの「使い方・はじめに」から案内を開き直せます。案内を終えたかどうかだけをブラウザに保存します。

## A：観光客と英語案内

1. `/profile` でニックネーム・English・通常歩行を保存する。
2. マップで福山駅前の模擬出発点と地震の避難先候補を見る。
3. 災害バナーの「Read guidance」を押す。Gemini未設定ならTemplateと明記した英語固定文が表示される。

## B：階段回避

1. プロフィールを通常歩行・階段回避OFFにする。
2. マップの災害種別を「津波」にする。高台避難候補にr2の階段が含まれる。
3. プロフィールで車いす、または階段回避をONにする。
4. マップに戻るとr2を通らない候補へ変わり、距離が増える。

## C：2人での支援

1. タブAで依頼者のプロフィールを保存する。位置共有をONにする。
2. タブBで同じアプリを開く。ローカルデモでは別IDが発行される。
3. タブBで支援者のプロフィールを保存する。「道案内」「支援に協力できる」「位置共有」をONにする。
4. タブBの支援者画面で「選択中の位置を共有する」を押す。
5. タブAで支援内容を選び、共有に同意→内容確認→依頼する。
6. 支援状況画面で「候補を探す」を押す。
7. タブBに3秒以内を目安に依頼が表示される。「同意して承諾」を押す。
8. 両方の画面で、承諾と同じ「模擬合流地点」・双方の移動時間目安が表示されることを確認する。承諾前には地点を表示しない。
9. 「合流へ進む」→「合流した・支援開始」→「支援を完了」を操作し、両方の画面で状態の同期を確認する。

当事者の正確な現在地は相手へ公開せず、架空の道路ノードを合流地点として表示します。地点は承諾時の条件による計算結果で、道路変更後に再計算しません。条件が変わったら中止して再依頼してください。このデモは候補評価・状態同期の検証です。タブを再読み込みするとローカルデモのIDは変わります。Firebase認証では同じブラウザのタブは同じ匿名ユーザーを共有するため、別ブラウザ／別プロファイルを使用してください。

## D：道路閉塞

1. 地震・通常歩行・福山駅前で、みどり広場へr3を通る400mの初期候補を確認する。
2. `/admin` で模擬管理操作を有効にし、r3をClosedにする。
3. マップへ戻る。5秒以内を目安にr3を通らない候補へ変わる。
4. r1とr3を両方Closedにすると駅前が孤立し、経路なしと表示される。
5. Unknownでも道路は除外される。終わったらOpenへ戻す。

## 検証記録

自動テストは模擬データを使ったAPIと業務ロジックを対象にします。ブラウザでは初期マップ表示、プロフィール、支援の送信、道路操作を確認します。実GPSの許可、Google Mapsのキー、Firebaseクラウドでの支援フロー全体、Gemini実呼出し、スマートフォン実機は別途確認が必要です。

## 期限切れと再探索を試す

1. 依頼者と支援者を別のデモタブで準備し、オファーを作る。新しいオファーには承諾期限が表示される。
2. 支援者は承諾せず5分待つ。3秒ごとの取得でマッチが「有効期限切れ」、依頼が候補探索待ちに変わる。
3. 依頼者は「別の候補を探す」を押す。同じ依頼で期限切れになった支援者は除外される。
4. 未試行の支援者がいなければ候補なしの案内が表示される。依頼を取り消すと新規要請やプロフィール変更ができる。

期限判定はサーバーで行います。端末時刻から状態を確定したり、自動で次の相手に依頼を送ったりしません。テストでは時間を進めて、期限ちょうど・承諾や取消との競合・Firestore保存を確認しています。

## スマートフォン表示の確認

Chromeの開発者ツールで320px・390px幅を指定し、日本語・英語のホーム、プロフィール、支援依頼、支援協力、支援状況を確認します。640px以下では下部ナビを使用し、支援状況は「支援依頼」を選択状態にします。上部にはアプリ名・使い方・言語切替を残し、ページタイトルは本文で表示します。候補カード・フォームは1列で、入力・ボタンと長い同意文が画面内に収まるかを確認してください。末尾の操作が下部ナビに隠れないことも確認します。実機ではキーボード表示中の入力・保存、端末の安全領域を別途確認してください。
