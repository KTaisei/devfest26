## 現在の段階：Firebase基本接続完了、支援フローを改善中

チームのFirebaseは **`tasuku-77c63`** です。APIの認証・Firestore保存・復元に加え、ブラウザからのプロフィール保存・再読み込みを確認しました。通常起動時の空のエミュレータ環境変数による接続不良も修正済みです。

Google Mapsはブラウザ用キーを設定し、ローカルで背景地図・架空マーカー・模擬経路の表示を確認しました。Geminiのキーは設定済みですが、実呼び出しが前払いクレジット残高不足（402）で失敗し、定型案内へ切り替わっています。残高・請求設定の確認後に再検証します。各端末のGit管理外 `.env.cloud` に設定してから実接続を確認します。この待ち時間に、5分のオファー失効・画面反映・別候補の手動再探索を実装しました。共有ブランチの合流地点共有と初回案内も統合し、災害種別・合流後の経路の検証を補強しました。自動再依頼は行わず、利用者が候補を再探索します。

共同開発者の初回接続は [SETUP.md](SETUP.md) と [WINDOWS.md](WINDOWS.md) に従います。各自のGoogleアカウントでADCを設定し、秘密鍵ファイルは共有しません。クラウド用起動は `npm run dev:api:cloud` と `npm run dev:cloud` です。課金の有効化やデプロイはこの作業では行っていません。

## 毎回の進め方

1. GitHubの更新を取得し、差分と既存の作業を確認する。
2. 今の段階に必要な変更を、小さくまとまる単位で実装する。
3. 該当するテストとビルドを実行し、未検証事項を残す。
4. 説明と検証記録を更新し、コミット・プッシュする。

次はGeminiの設定を確認して実接続を検証し、その後に公開デモ・モバイル表示の仕上げへ進みます。公式災害情報や実道路データへの対応は、模擬データのMVPとは別に検証します。
