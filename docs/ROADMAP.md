## 現在の段階：Web実データ試験と実用化の準備

ユーザーからスマートフォンでの動作と合流までの確認報告を受けました。次の段階として、Webの実道路試験画面・GPS取得・プロフィール別時間概算・地震公開情報・ストリートビューリンクを追加しました。既存の支援には模擬合流地点までの経路表示を追加しています。実データの安全性を検証したアプリにはまだ到達していません。[実データ対応の境界と残作業](REAL_DATA.md)を参照してください。

チームのFirebaseは **`tasuku-77c63`** です。APIの認証・Firestore保存・復元に加え、ブラウザからのプロフィール保存・再読み込みを確認しました。通常起動時の空のエミュレータ環境変数による接続不良も修正済みです。

Google Mapsはブラウザ用キーを設定し、ローカルで背景地図・架空マーカー・模擬経路の表示を確認しました。AI Studio方式では残高不足（402）だったため、Vertex AIへ切り替え、既存ADCで日本語・英語の生成を確認しました。クレジット適用状況は請求画面で別途確認します。各端末のGit管理外 `.env.cloud` に設定してから実接続を確認します。この待ち時間に、5分のオファー失効・画面反映・別候補の手動再探索を実装しました。共有ブランチの合流地点共有と初回案内も統合し、災害種別・合流後の経路の検証を補強しました。自動再依頼は行わず、利用者が候補を再探索します。

共同開発者の初回接続は [SETUP.md](SETUP.md) と [WINDOWS.md](WINDOWS.md) に従います。各自のGoogleアカウントでADCを設定し、秘密鍵ファイルは共有しません。クラウド用起動は `npm run dev:api:cloud` と `npm run dev:cloud` です。公開デモは https://tasuku-77c63.web.app 、更新方法は [DEPLOYMENT.md](DEPLOYMENT.md) にまとめています。

## 毎回の進め方

1. GitHubの更新を取得し、差分と既存の作業を確認する。
2. 今の段階に必要な変更を、小さくまとまる単位で実装する。
3. 該当するテストとビルドを実行し、未検証事項を残す。
4. 説明と検証記録を更新し、コミット・プッシュする。

次はWeb実道路試験の実機確認、実在する避難先・合流候補と入口のデータ整備、階段・幅員・勾配等の確認へ進みます。緊急地震速報は配信サービス未契約、ARはWebを優先するため未実装です。速報の再配信条件を確認してから常時受信基盤を実装します。
