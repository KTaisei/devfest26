# 前景GPS・音声案内とGemini判断補助

2026-11-10追加。すべて訓練・試験表示です。Google Mapsアプリと同等の品質・バックグラウンド常駐・実災害向けの利用を保証しません。ARは追加していません。

## 操作

1. `/home` でGPS取得、目的地選択、経路計算への同意後、「徒歩の道順を表示」を押します。支援の承諾後は `/support` または `/helper` で「自分の現在地から合流地点への道順」を押します。
2. 道順にある連続GPS・経路再計算・ブラウザ音声への同意を選び、「GPS・音声案内を開始」を押します。専用の全画面地図で現在地を追従し、次の曲がり角・残り距離・時間目安・GPS精度を表示します。
3. 音声はブラウザのSpeechSynthesisです。提供元やオンライン利用は端末・ブラウザの音声エンジンに依存します。音声に個人名や他人の座標を含めません。「消音」「もう一度案内」「案内を終了」を使えます。非対応時は画面案内を使います。
4. 経路外の有効GPSが3回続いた場合は、開始時の送信同意に基づき本人の現在地から同じ目的地へ再計算します。最低30秒間隔で、同時の重複要求を防ぎます。失敗時は経路外の注意を維持し、架空道路には切り替えません。
5. タブの背景化・別画面への移動・終了でGPS watchと音声を停止します。再開には開始操作が必要です。画面ロック中やOSに停止された後の案内は提供しません。
6. 目的地付近を推定して案内を終了します。これは入口の確認や対面合流の証明ではありません。合流は従来どおり、双方の目視確認と別操作が必要です。

## GPS進行判定

- 全体の実道路形状へ投影した距離を使い、単純な直線距離だけで曲がり角や到着を判定しません。
- 精度35m超、10秒超古い位置、未来2秒超の位置は進行させず、案内を保留します。10秒更新がない場合も保留します。
- 前進範囲を時間と精度で制限し、経路が近くで交差しても遠い区間へ飛ばないようにします。後退方向のGPS揺れでは進行を戻しません。曲がり角を8m通過してから次区間へ進めます。
- 目安50m・15m以内で次の案内を読み上げます。同じ区間・段階の繰り返しを抑えます。
- 経路残り20m以内かつ終点から20m以内の有効位置が2回続いた場合だけ、目的地付近と推定します。GPS停止や精度低下時は連続回数をリセットします。
- 建物内・高架下・並行道路・折返し・短い区間での実用精度、発話のタイミング、各OSの停止条件は屋外実機で未検証です。これは独自の試験用進行処理で、Google Navigation SDKではありません。

## 支援情報の自動取得

プロフィールで位置共有・支援受付・対応能力を設定します。支援画面でGPSと検索への同意を行うと、協力者の周辺依頼は5秒、本人の依頼・承諾・合流確認状態は3秒ごとに自動取得します。ページの再読み込み操作は不要です。ネットワーク通信自体が不要という意味ではありません。

一時的な保存競合が続く場合は再試行可能なエラーを表示します。既存の一覧を取得中も残し、初回取得・失敗・条件に合う依頼なしを区別します。GPS取得から5分後、同意撤回、画面遷移、受付無効で周辺検索を止めます。再開時は新しいGPSと同意が必要です。相手の正確な位置は取得しません。

## Geminiが担当すること

**合流候補比較**：依頼時と承諾時に双方が追加同意した場合だけ使用します。両者の2km圏内の公開候補を近い順に最大3件取り、各自30分以内の通常徒歩経路が確認できたものだけを比較します。AIに渡すのは候補順と匿名化した「合計秒数・長い方の秒数」だけです。座標・住所・施設名・個人の所要時間・利用者ID・個人設定は送りません。AIは候補indexだけを返し、バランスを優先して選択します。最短合計より120秒超長い候補は採用しません。安全性や入口の確認は行いません。

**避難状況の整理**：`/home` の操作パネルを開き「Geminiで状況を整理する」から、本人が観測した揺れ・通行障害を申告します。追加同意後、地域の地震情報の取得状態・件数と本人の支援状態を合わせ、次に確認する行動を提案します。情報不明を安全と見なしたり、本人の申告から救助対象を推測したりしません。確認行動の候補はサーバーのルールで限定します。

いずれもAIの自由生成文・座標・経路をそのまま使いません。構造化結果を検証し、未設定・停止・タイムアウト・候補外回答・余分な出力・不完全な出力は固定ルールに戻します。UIはGeminiとルールによる提案を区別します。既存の `GEMINI_BACKEND=vertex` 設定とADCを使えます。AI Studioキーへの自動切替はありません。

## 検証

Mac・Windows共通：`npm run test:navigation`、`npm run test:backend`、`npm run build`。API契約を変更したため `npm run api:export`、`npm run api:types` を実行します。CIの両OSでも進行判定テストを実行します。

ローカルの純粋関数テストは曲がり角、GPS揺れ、古い位置、精度不良、経路外、位置の飛び、折返し近くでの誤到着を確認します。サーバーは匿名入力、候補外出力の拒否、同意、既存の承諾競合・位置の非公開を確認します。実機での連続GPS・音声・マイク不要の音声出力、合流フロー全体、実Vertexでの新しい構造化出力の検証状況は [TESTING.md](TESTING.md) に記録します。
